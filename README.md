# Which Version of Me Do You Meet?

A personal hypertext narrative exploring three sides of my personality: the Builder, the Student, and the Dreamer.

The Builder wants to fix and improve things. The Student is still figuring things out. The Dreamer is always thinking about what comes next. Their paths overlap, revealing the pressure of constantly moving forward and the quieter possibility of taking a pause.


Start by choosing Builder, Student, or Dreamer. Follow the linked thoughts and decide where to go next. You can revisit another side of me, return to the beginning, or take a different path.

There is no single correct order. The choices you make shape how you experience the narrative.

[Enter the narrative](https://saniyaaziz2003.github.io/hypertext-narrative/) 

## About the Project

I designed the initial narrative in Figma and developed the coded version using HTML and CSS. The project contains 11 connected HTML pages, with hyperlinks that create branching paths and loops.

The black background, handwritten headings, and thought fragments reflect the feeling of moving between different ideas and versions of myself.

Created for my Hypertext Narrative course assignment.
